# Random forest 
It is a learning method which combines multiple decision trees to produce more accurate and stable prediction.
-> MULTIPLE DECISION TREES: Builds many trees and combines their prediction.
-> ENSEMBLE APPROACH: reduces errors compared to a single decision tree.
->REGRESSION PREDICTION: Produces continuous values by averaging prediction from all trees.
